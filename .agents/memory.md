# NSB 项目记忆

## 架构与优先级

- 桌面端使用 Go / MyGo native desktop，MyGo 锁定 v0.6.1。
- 项目按 `gui/core/server` 分层：`gui/app` 实现原生页面，`gui/desktop` 管理内核与桌面服务，`core` 负责订阅解析、组合及存储；`server` 是独立 HTTP 服务入口，目前提供健康检查骨架，职责定位为云端组合订阅计算。
- Desktop 直接调用本地服务，通过 HTTP client 访问 sing-box Clash API。
- 当前处于复刻阶段，聚焦 Windows、页面还原和主要功能。优先 MyGo 自带组件，保持清晰、精简的代码结构；验证范围与改动匹配。
- Windows 程序和 setup 均通过 MyGo build 产出。
- Desktop Open 将配置与数据目录解析为绝对路径，内核启动切换工作目录后仍使用完整的程序和配置路径。

## 界面约定

- 视觉规范见 `DESIGN.md`：青灰网络控制台，当前链路与主要操作使用青色强调，浅深主题共享语义角色。
- 中文使用 Microsoft YaHei UI，英文使用 Segoe UI；页面标题 22px/600，正文 14px，次级文字 12px。页面标题直接连接工具栏与内容。
- 图标在 `gui/app/style.go` 统一维护：24px SVG 网格、1.8 描边、圆角端点；优先 MyGo 组件，应用 Logo 保持现有资源。
- 导航宽 232px、项目高 42px，面板圆角 10px、控件和节点圆角 6px；模板使用单行紧凑布局，当前订阅和节点带强调边框。

- 左侧 Sidebar；常规内容区居中，最大宽度 1320px，左右内边距 28px。搜索框限制宽度。
- 页面滚动条贴应用内容区右边缘：外层 Scroll 全宽，限宽和 padding 放在它内部的内容容器；嵌套表格、代码编辑器等内部滚动除外。
- 各页标题、固定工具栏、正文共用限宽与左右边界；工具栏位于面板外，与正文间距 16px，搜索框通常宽 360px、高 36px，代理页宽 120–360px 随同排筛选空间伸缩，页级按钮高 36px。设置分组间距 16px，列表卡片间距 12px。
- 代理页分组/节点列表在统一限宽内随窗口宽度增加列数。所有 proxy card 等高等宽，固定高度 76px，内容紧凑排列。
- 代理分组顺序：PROXY、当前订阅对应的来源组、其他组、GLOBAL。
- 代理页支持组导航、组内定位当前节点、原序/名称/延迟排序，以及隐藏已测速失败的节点；未测速节点和当前选中节点保留。测速提供单节点、组、全部三种范围，去重后最多并发 4 个，可停止；切换订阅、重启或停止内核时取消并清空旧结果。
- 代理页搜索、组导航、排序和隐藏无效节点同排，路由模式与全部测速放在标题右侧。
- 代理页操作使用纯图标 Text Button，默认透明、悬停显示主题底色，保留 tooltip 与可访问名称；排序和组导航使用原生选择控件。
- 单节点测速只禁用该节点的测速按钮，其他节点可独立发起；单节点与批量测速共用最多 4 个请求的并发上限，批量测速跳过正在测试的节点。
- 代理初始化“准备连接网络”空态容器也要左右留白、居中限宽；底部消息提示栏左右 28px、底部 16px 留白。
- Segmented 控件按内容定宽。
- 订阅使用以名称和信息为主的紧凑卡片/列表。
- 订阅行的使用、更新、编辑、生成配置、删除操作使用带悬浮提示的纯图标 Text Button，与代理页操作一致。
- 订阅表单将名称/模板、间隔/Cron、来源名称/格式分别并排；短字段限制宽度，URL 使用横向标签，代码编辑器保留整行，来源操作合并为一行。
- 日志及连接页面内容限宽。日志整行按 level 着色，字号 14px，最新记录在前；level 使用 Checkbox 多选 TRACE/DEBUG/INFO/WARN/ERROR/FATAL，默认全选。
- 设置支持导入内核；左下角提供普通次级样式的“重启内核”按钮。
- 底部状态栏单行截断错误摘要，有内核日志时提供“查看日志”入口；启动退出错误的完整输出留在日志页。
- 日志工具栏固定在正文滚动区上方，与正文面板间距 16px；正文在固定边框内部滚动。清空操作隐藏本次会话的已有记录，保留磁盘日志，继续显示新记录。

## 验证与打包

- 使用稳定的 MyGo keys，Element 生命周期限定于当前 build，持久状态保存数据、控件状态或 Handle；后台结果通过 Window.Update 发布。
- 按改动运行针对性检查，原生 UI 检查包括相关 GUI 测试及 `go tool mygo vet .`。
- Windows 打包：`go tool mygo build -platform windows/amd64 -o dist/<名称> .`。
- 产物位于 `dist/<名称>/windows-amd64/`，包含 `NSB.exe` 和 `NSB Setup <版本> amd64.exe`。每次试用打包使用新目录，保持用户当前实例运行；切换单实例程序前由用户从托盘退出旧实例。
